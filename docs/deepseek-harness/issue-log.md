# DeepSeek Harness 问题日志

## 目的与维护位置

记录异常事实、阻塞与处理证据，避免重复失败。本文件由 `11-issue-log-recorder.md` 维护，位置为文档仓库的 `docs/deepseek-harness/issue-log.md`；不另建 `testing/` 路径，也不是独立调度入口。

## 记录规则

按“仓库 + 对象 + HEAD/事件 + 根因”去重。记录必须区分已核实事实、推测和未验证事项；未真实重跑、恢复、合并或验收时不得写成完成。

重大变化通过独立文档 PR 保存；同一问题无变化时不重复提交、评论或创建 Issue。日志和 PR 描述必须脱敏。维护记录不授权修改源码、CI、权限规则、其他 Agent 分支或自动关闭 Issue。

## 记录格式

- 问题编号与日期：
- Agent 与任务名称：
- 仓库、Issue/PR、当前 HEAD SHA：
- 触发类型、delivery、run attempt、计划版本及去重键：
- 首次/最近发生时间与累计修复/恢复次数：
- 已核实问题与证据链接：
- 原因（已核实、推测或未验证）：
- 影响范围与阻塞原因：
- 实际处理动作与结果：
- 负责 Agent 与下一动作：
- 是否需要人工审批或规则调整：
- 状态（待处理、处理中、阻塞、已验证解决）：
- 解决证据与关联验收用例：
