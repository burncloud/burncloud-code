# DeepSeek Harness 单Agent验收记录

## 范围与真实证据

记录一个原生定时入口和一个执行Agent的验收设计，由00按10职责维护。01至11是阶段规范，不是分别注册的任务。既有[行为用例](../deepseek-harness-evaluation/test-cases.md)与[运行档案](../deepseek-harness-evaluation/runs/)只读引用。

以下均为“未执行”。保留旧ST/COMM编号，未执行场景按单Agent方案更新；旧9任务并发/逐阶段交接不再作为目标。文档审查与本PR远端CI不等于实际Harness安装、单Agent运行或成本下降。

## 每次实际记录

- 用例编号、日期、Harness版本、Prompt commit SHA、唯一入口与实际运行ID/执行者数。
- 根task_key、scope_key、Issue/PR完整URL、计划版本与checkpoint message_id/comment ID/URL及前序来源。
- 预期与实际操作、已用阶段、本轮事实/分析复用情况、重复API/文件读取/Diff或日志分析次数、内部交接留言数量。
- 真实HEAD/merge SHA、目标包含结果、CI run/job/check/attempt/URL/实际覆盖、正式Review与保护核验。
- 原生运行/互斥及旧任务实际停止/迁移证据，根因链与累计修复/重跑/恢复次数。
- 未缓存输入、缓存读取/写入、输出token、实际费用与完成业务工作量；无法观测项标未验证。
- 验证级别（文档审查、历史核验、实际Harness执行、远端CI），结果（未执行/通过/失败/阻塞/证据不足）、问题编号和下一动作。

不得本地执行编译/测试或为验证禁令启动违规命令。只用已有授权对象观察Harness，不制造测试Issue/PR。必要代码测试在GitHub Actions执行；没有实际证据保持未执行或证据不足。
