# DeepSeek Harness 验收记录

## 目的与记录边界

记录中文定时任务集合的验收标准及真实运行证据。本文件由 `10-test-case-recorder.md` 维护；不另建 `testing/` 路径，也不是独立定时任务 Prompt。

以下是验收设计，初始状态均为“未执行”。文档内容检查不等于 Harness 运行验收或 GitHub CI 通过。现有[行为回归用例](../deepseek-harness-evaluation/test-cases.md)与[运行档案](../deepseek-harness-evaluation/runs/)继续保留。

不得在本地执行这些测试；必要执行交给 GitHub Actions 或读取已有真实记录。不得为了验证禁令而在用户本机启动编译或测试。没有证据时保持“未执行”或“证据不足”。
