# DeepSeek Harness CI失败参考（不独立注册）

只有00是定时入口，CI诊断属于同一Agent的05阶段。当前方案不创建事件任务、CI Agent、Webhook或外部队列；本文件只说明失败分类，不作为安装清单。

| 真实原因 | 同一执行者的动作 |
|---|---|
| 源码/测试失败 | 05汇总当前HEAD日志与预算，直接转03修复，不重新读取全部上下文 |
| 临时Runner/网络问题 | 05在已有授权内最多重跑一次，未知结果先查run/attempt |
| 覆盖缺口或持久基础设施问题 | 记录阻塞，按需11记日志；禁止修改CI或本地复现 |
| 排队、进行中、取消、超时、跳过 | 查询日志与实际状态，不一律归因源码；等待无变化则结束 |
| 旧HEAD/旧attempt、关闭PR或外部对象 | 不修旧分支、不重跑、不合并；外部对象只读 |

同轮共享诊断结果，业务变化并入聚合检查点，不为每Job或阶段发回执。新HEAD必须重新取得有效CI/Review证据，预算沿原根因链累计。未来任何事件增强都需另行授权，不应重新创建多个Agent重复处理同一CI。
