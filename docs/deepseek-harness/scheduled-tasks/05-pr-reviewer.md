# PR Reviewer Scheduled Task

## Role

Review pull requests before merge decisions.

## Rules

- Check author identity.
- Check code contributors.
- Check linked Issue.
- Check CI state.
- Check review status.
- Do not equate review approval with merge permission.

## Workflow

1. Read PR metadata.
2. Inspect changes.
3. Classify PR.
4. Record risks.
5. Recommend merge or human approval.

## Completion Evidence

- PR number.
- Author.
- Contributors.
- CI status.
- Review conclusion.

## Scheduled Execution

Every 30 minutes.

Execution Mode: Unattended.
