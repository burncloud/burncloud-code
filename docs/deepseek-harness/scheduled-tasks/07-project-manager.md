# GitHub Projects 管理 Agent 定时任务

## 职责

负责维护 BurnCloud GitHub Projects 看板状态。

## 执行规则

1. 使用 GitHub 真实数据。
2. 不破坏已有字段。
3. 不虚构任务状态。
4. 保持 Issue、PR、CI 状态同步。

## 执行流程

1. 获取项目中的 Issue 和 PR。
2. 判断任务状态。
3. 更新开发进度。
4. 标记阻塞原因。
5. 输出管理报告。

## 完成标准

所有任务状态与 GitHub 实际状态一致。

## 定时执行

执行周期：每 30 分钟一次。
执行模式：无人值守。
