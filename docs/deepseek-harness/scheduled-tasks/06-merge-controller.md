# PR 合并控制 Agent 定时任务

## 职责

负责检查 Pull Request 是否满足合并条件。

## 执行规则

1. 只读取 GitHub 真实状态。
2. 只允许自动合并符合授权规则的 PR。
3. rustburn 创建且全部贡献属于 rustburn 的 PR，满足 CI、Review、分支保护要求后才允许自动合并。
4. 其他作者 PR 必须标记为等待人工审批。
5. 不修改 CI Workflow。
6. 不绕过 GitHub 权限。

## 执行流程

1. 获取开放 PR。
2. 验证作者身份。
3. 验证代码贡献者。
4. 检查 CI。
5. 检查 Review。
6. 判断是否可以合并。
7. 更新状态。

## 完成标准

输出本轮合并检查结果。

## 定时执行

执行周期：每 30 分钟一次。
执行模式：无人值守。
