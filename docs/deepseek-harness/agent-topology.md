# DeepSeek Harness 单Agent执行关系

唯一执行者是00自主研发定时任务的Agent。01至11是它内部按需使用的阶段规范，阶段编号不是Agent编号。阶段之间共享本轮上下文与事实快照，不派发、回调、创建子Agent或多模型工作流。

| 当前工作 | 同一执行者的处理 | 可复用信息 |
|---|---|---|
| 新授权Issue | 发现、规划，满足条件后直接开发 | 身份、需求、依赖和文件范围 |
| 活动PR | 查询CI、分析变化Diff、自检、修复或等待 | 当前HEAD、计划、日志与已有结论 |
| 可能合并 | 实时重核全部门禁与原有授权 | 分析结论可复用，实时门禁必须重读 |
| 状态/证据变化 | 同轮更新看板、验收和日志 | 本轮已经验证的业务结果 |
| 异常或恢复 | 核验实际停止、原生互斥、远端动作再安全续接 | 原分支、检查点、预算和真实API结果 |

## 数据与权限

同轮结果直接用于下一必要步骤，仅在业务实际变化或动作意图/结果需要跨轮保存时追加聚合检查点。新轮次从授权Issue/PR留言恢复，缓存/会话是可丢弃优化；Project及记录文件仅作展示/审计。

一个执行者不能省略职责约束。03阶段修改源码，04仅自检/读取正式Review，05仅CI诊断与有限授权重跑，06仅受保护合并，07至11仅元数据/指定记录或安全恢复。切换阶段不能增加权限，自检不能代替独立Review，普通留言不能授权合并或关闭Issue。

原生运行/互斥须实际核验；活跃旧执行者不能被新入口接管。先停止旧定时任务并核验真实停止，再迁移已有分支、PR和检查点。迁移不能清空预算、覆盖成果或改写历史留言。
