# DeepSeek Harness 定时任务总览

## BurnCloud 自主研发管理任务

由 Harness 调度器周期执行。

| 任务 | 周期 | 职责 |
|---|---|---|
| Issue 扫描任务 | 每30分钟 | 发现和检查研发任务 |
| 任务规划任务 | 每30分钟 | 分解可执行工作 |
| Projects 管理任务 | 每30分钟 | 同步 GitHub 看板 |
| PR 审查任务 | 每15分钟 | 检查代码和需求符合性 |
| CI 守护任务 | 每10分钟 | 检查最新 HEAD CI 状态 |
| 合并控制任务 | 每10分钟 | 执行自动合并门禁 |
| Harness 观察任务 | 每30分钟 | 记录 Agent 行为问题 |
| 故障恢复任务 | 每30分钟 | 恢复异常流程 |

## 无人值守规则

- 不等待普通技术决策。
- 不重复创建任务。
- 不依赖人工逐轮确认。
- 无任务时结束本轮等待下一次调度。

## 持久化

所有执行结果必须保存在 GitHub 可追踪位置。
